One original fortune-cookie line for a software developer, written for the
[Fortune Cookie Wisdom for Developers](https://make.fun/c/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
competition on make.fun.

## The entry

> The legacy code you fear was written by someone who feared it too, and left you a map in the comments.

102 characters. One sentence, one breath, in the voice of a tired senior
engineer: the legacy code that scares you was written by someone who was
scared of it too — and the comments they left behind are the map they drew
for you, not the mess you assumed they were.

## How it works

`main.ts` writes that single fixed line to `/output/entry.txt`. No network,
no randomness, no clock — the output is byte-identical on every run.

```sh
node main.ts
cat /output/entry.txt
```
